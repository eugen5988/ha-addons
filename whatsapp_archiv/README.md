# WhatsApp-Archiv

Medien-Viewer für ein WhatsApp-Archiv, das auf dem NAS liegt.

- Alle Chats mit Suche, je Chat **Fotos, Videos, Sprachnachrichten und Dokumente**.
- Filter nach Jahr, Gruppierung nach Monat, Vollbild mit Wischen.
- Schnell auch bei zehntausenden Medien dank Vorschaubildern.
- Läuft in der Seitenleiste von Home Assistant und damit auch in der HA-App unterwegs.

Das Archiv selbst wird mit der Mac-App „WhatsApp-Archiv“ aus einem iPhone-Backup erstellt.
Details stehen im Reiter **Dokumentation** des Add-ons.
