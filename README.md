# Home Assistant Add-ons von eugen5988

Eigene Add-ons für Home Assistant OS bzw. Supervised.

## Installation

1. In Home Assistant: **Einstellungen → Apps → App Store**, oben rechts **⋮ → Repositories**.
2. Diese Adresse eintragen und hinzufügen (genau so, ohne Schrägstrich am Ende):

   ```
   https://github.com/eugen5988/ha-addons
   ```

3. Das Add-on erscheint im App Store unter „eugen5988 – Home Assistant Add-ons“.

## Add-ons

| Add-on | Beschreibung |
|---|---|
| [Ausgaben](ausgaben/) | Haushaltsbuch mit automatischer Erfassung (Trade Republic, DKB, comdirect), Kassenbon-Scan und KI-Kategorisierung |
| [WhatsApp-Archiv](whatsapp_archiv/) | Medien-Viewer für ein WhatsApp-Archiv auf dem NAS – Fotos, Videos, Sprachnachrichten und Dokumente je Chat |

## Updates

Neue Versionen meldet Home Assistant selbst. Sofort nachsehen: App Store → ⋮ → **Nach Updates suchen**.
Was sich geändert hat, steht im jeweiligen `CHANGELOG.md` und wird beim Update angezeigt.
